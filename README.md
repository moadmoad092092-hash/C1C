# تحويل الموقع إلى تطبيق Android



أداة بسيطة لإنشاء APK حقيقي يعمل كغلاف Android WebView للموقع الذي يدخله المستخدم.



## ملاحظة النشر



GitHub Pages يستضيف الواجهة الثابتة فقط. إنشاء APK يحتاج خادم Node.js مستقلًا يشغّل Android SDK وGradle. لا يُعرض زر تنزيل APK على أنه جاهز قبل نجاح البناء الفعلي.
